## FIX 1 — BOTÃO “COMPARTILHAR IDENTIDADE DE LEITURA” (card do perfil)

O botão no card escuro de Impressão de Leitura (“Compartilhar identidade de leitura”) não está funcionando. Precisa funcionar mesmo quando o perfil ainda está “em formação” (sem arquétipo calculado).

### Implementação

No `ProfileScreen.tsx`, localizar o botão de compartilhar dentro do card de Impressão de Leitura e substituir o handler por:

```typescript
const handleShareReaderIdentity = async () => {
  // Funciona em QUALQUER estado — com ou sem arquétipo calculado
  const archetypeText = currentArchetype ?? "Leitor em formação";
  const signature = profile?.reading_signature ?? profile?.bio ?? "Cada livro me deixa diferente";
  const username = currentUser?.username ?? currentUser?.full_name ?? "leitor";

  try {
    const blob = await generateShareCard({
      type: "reader_identity",
      archetype: archetypeText,
      readingSignature: signature,
      username: username,
      format: "story",
    });

    const file = new File([blob], "marginalia-identidade.png", { type: "image/png" });

    if (navigator.canShare?.({ files: [file] })) {
      await navigator.share({
        files: [file],
        title: "Minha identidade de leitura — Marginalia",
        text: `Meu perfil de leitura no Marginalia: ${archetypeText}`,
      });
    } else {
      // Fallback: download direto
      const url = URL.createObjectURL(blob);
      const a = document.createElement("a");
      a.href = url;
      a.download = "marginalia-identidade.png";
      document.body.appendChild(a);
      a.click();
      document.body.removeChild(a);
      URL.revokeObjectURL(url);
    }
  } catch (err) {
    console.error("Erro ao compartilhar:", err);
  }
};
```

**Importante:** o botão deve estar habilitado (`opacity: 1`, clicável) em TODOS os estados do card — incluindo o estado “Seu perfil ainda está se formando”. Remover qualquer condição que desabilite o botão. Mesmo sem arquétipo, o usuário pode compartilhar o card com o texto “Leitor em formação”.

Se o arquivo `shareCard.ts` (geração via Canvas) ainda não existir ou não tiver a função `generateShareCard`, criar um fallback simples que usa a Web Share API com texto apenas:

```typescript
// Fallback se generateShareCard não estiver disponível
const shareText = `Minha identidade de leitura no Marginalia\n\n${archetypeText}\n\n"${signature}"\n\nmarginalia.replit.app`;

  await navigator.share({
    title: "Marginalia — Identidade de Leitura",
    text: shareText,
    url: "https://marginalia.replit.app",
  });
} else {
  await navigator.clipboard.writeText(shareText);
  // Feedback visual: trocar texto do botão por "Copiado!" por 2 segundos
}
```

- Animação suave na troca: `transition: opacity 200ms`

### Implementação do tema

Criar um contexto de tema ou usar o que já existe. Salvar preferência em `localStorage` com a chave `mg_theme_${userId ?? 'default'}`.

```typescript
// src/context/ThemeContext.tsx
import { createContext, useContext, useEffect, useState } from "react";

type Theme = "light" | "dark";

const ThemeContext = createContext<{
  theme: Theme;
  toggleTheme: () => void;
}>({ theme: "light", toggleTheme: () => {} });

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => {
    return (localStorage.getItem("mg_theme") as Theme) ?? "light";
  });

  useEffect(() => {
    document.documentElement.classList.toggle("dark", theme === "dark");
    localStorage.setItem("mg_theme", theme);
  }, [theme]);

  const toggleTheme = () => setTheme(t => t === "light" ? "dark" : "light");

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);
```

Envolver o app com `<ThemeProvider>` no `main.tsx` ou `App.tsx`.
