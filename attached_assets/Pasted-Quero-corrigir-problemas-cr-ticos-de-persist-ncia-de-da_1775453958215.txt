Quero corrigir problemas críticos de persistência de dados, UX e performance no app.

Esses pontos são PRIORIDADE MÁXIMA, pois afetam diretamente a confiabilidade do produto.

--------------------------------------------------
1. BUG CRÍTICO: PERFIL NÃO SALVA (Instagram, TikTok, cor da bolinha)
--------------------------------------------------

Atualmente, quando o usuário:
- preenche Instagram
- preenche TikTok
- escolhe a cor da bolinha/avatar

e clica em salvar, os dados NÃO persistem.

Isso é inaceitável. Precisa corrigir completamente.

### O comportamento correto deve ser:

- ao clicar em salvar, deve executar um UPDATE na tabela `profiles` do Supabase
- usar o `auth.uid()` como referência do usuário
- todos os campos devem ser enviados corretamente no update

### Campos obrigatórios no update:
- instagram_handle
- tiktok_handle
- avatar_color
- bio
- full_name
- username

### Após salvar:
- os dados devem ser recarregados imediatamente do Supabase
- a UI deve refletir os novos dados sem precisar refresh manual
- ao sair da conta e voltar, os dados devem continuar lá

### IMPORTANTE:
- remover qualquer estado local/mock que sobrescreva dados reais
- garantir que o formulário esteja ligado ao estado vindo do banco
- garantir que não exista overwrite por valores default após salvar

--------------------------------------------------
2. PERSISTÊNCIA ABSOLUTA DE DADOS DO USUÁRIO
--------------------------------------------------

O app deve funcionar como um sistema persistente real.

Regra fundamental:

"Nunca perder nenhuma ação do usuário."

### Isso significa:

- tudo que o usuário fizer deve ser salvo no banco
- dados devem sobreviver:
  - refresh
  - logout
  - login novamente
  - troca de tela

### Inclui:

- progresso de leitura
- reações (emoji)
- ecos criados
- comentários
- perfil (bio, redes sociais, cor, etc)
- livros adicionados
- preferências

### Implementação:

- sempre usar Supabase como fonte de verdade
- evitar depender apenas de state local
- após qualquer ação → sincronizar com banco
- ao carregar tela → sempre buscar do banco

--------------------------------------------------

### Nunca deve acontecer:
