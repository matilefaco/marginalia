Quero que você implemente o aplicativo MARGINALIA em React, com arquitetura limpa, componentes reutilizáveis, navegação real, dados mockados consistentes e experiência mobile-first premium.

OBJETIVO
Transformar o protótipo atual em um front-end funcional de produto real.

IMPORTANTE
O app NÃO deve funcionar como e-reader.
Remover a lógica de páginas completas de leitura do livro.
O app deve ser centrado em:
- registrar trechos
- adicionar interpretações pessoais
- descobrir ecos de leitura de outras pessoas
- proteger o ritmo de leitura com anti-spoiler
- criar experiência social literária premium

STACK E DIREÇÃO TÉCNICA
Implementar em React com foco em front-end.
Pode usar:
- React
- CSS modular ou CSS-in-JS simples
- componentes reutilizáveis
- estado local com useState/useMemo
- contexto simples se necessário
- dados mockados internos
- navegação simulada por estado ou rotas leves, dependendo da estrutura existente

Se possível, organizar em:
- components/
- screens/
- data/
- hooks/
- utils/
- styles/

Se houver React Router já disponível, usar.
Se não houver, criar navegação simples por estado global/local, mas com sensação real de app.

UTILS IMPORTANTES
Criar utils para lógica de produto.

1. getBookProgress(userId, bookId)
Retorna progresso do usuário naquele livro.

2. canUserSeePost(post, spoilerPreference, progress)
Implementar a lógica anti-spoiler.

Regras:
- se spoilerPreference = all => true
- se spoilerPreference = progress_only => mostrar apenas se referência <= progresso
- se spoilerPreference = protected => bloquear conteúdos sensíveis e avançados
- se não houver progresso => mostrar apenas posts com spoilerLevel = none

3. getBlockedReason(post, userProgress)
Retorna texto elegante explicando por que o card foi ocultado.

4. getAvailablePostsForUser(posts, user, progressMap)
Filtra feed.

5. getReadingSignature(user, posts)
Pode ser mockado, mas estruturar como função.

6. getCompatibleReaders(user, users)
Pode usar lógica simples baseada em gêneros e livros em comum.
