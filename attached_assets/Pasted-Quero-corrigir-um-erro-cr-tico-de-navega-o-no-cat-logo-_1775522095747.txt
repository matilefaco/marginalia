Quero corrigir um erro crítico de navegação no catálogo de livros.

==================================================
1. PROBLEMA ATUAL
==================================================

Hoje, quando o usuário clica em alguns livros, ele é direcionado para a página de um livro diferente daquele que escolheu.

Ou seja:
- o card mostrado é de um livro
- mas a página que abre é de outro livro
- a navegação está associando alguns cards ao detalhe errado

Isso é um erro grave de experiência e confiança.

==================================================
2. COMPORTAMENTO CORRETO QUE EU QUERO
==================================================

Quando o usuário clicar em um livro específico, a página aberta deve ser exatamente a página daquele mesmo livro.

Exemplo:
- se o usuário clicar em “O Segundo Sexo”, deve abrir “O Segundo Sexo”
- se clicar em “Água Viva”, deve abrir “Água Viva”
- se clicar em “Assim Falou Zaratustra”, deve abrir “Assim Falou Zaratustra”

Nunca pode abrir a página de outro livro por engano.

==================================================
3. O QUE PRECISA SER REVISADO
==================================================

Quero que você revise toda a lógica de clique e navegação dos livros.

### Verificar especificamente:

#### 3.1. Identificador do livro usado no clique
- garantir que cada card esteja usando o `book.id` correto
- garantir que o clique não esteja usando índice da lista (`index`) como referência principal
- garantir que não esteja usando dados hardcoded
- garantir que não exista reuso incorreto de props

#### 3.2. Navegação para a rota/tela do livro
- conferir se o `navigate()` / `router.push()` / `Link` está recebendo o identificador correto do livro clicado
- garantir que o parâmetro passado na rota seja o `id` ou `slug` real do livro
- revisar se existe mapeamento errado entre card e detalhe

#### 3.3. Lista renderizada
- revisar o `map()` das listas de livros
- garantir que o card renderizado e o livro passado para o evento de clique sejam o mesmo objeto
- garantir que não exista fechamento errado de variável
- garantir que não exista reorder/filter/paginação quebrando a referência

#### 3.4. Query da página de detalhe
- garantir que a página de detalhe está buscando o livro com base no identificador recebido
- garantir que não esteja caindo em fallback errado
- garantir que não esteja abrindo sempre um “primeiro livro encontrado” ou “livro padrão”

#### 3.5. Slug / id / external_api_id
Se o sistema estiver misturando:
- `id`
- `slug`
- `external_api_id`

quero que você padronize isso.

Cada livro precisa ter uma referência única, consistente e confiável para abrir a página certa.
