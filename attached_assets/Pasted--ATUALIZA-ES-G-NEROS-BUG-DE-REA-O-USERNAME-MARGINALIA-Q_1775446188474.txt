2. BUG CRÍTICO — REAÇÕES (EMOJIS)

Problema atual:

Quando o usuário reage com um emoji em uma margem/eco:

→ TODOS os outros ecos ficam com o mesmo emoji selecionado

Isso indica que o estado está sendo compartilhado globalmente, e não por item.

⸻

2.1. Causa provável:
	•	estado de reação sendo armazenado de forma global
	•	não está sendo indexado por margin_id
	•	todos os componentes estão lendo o mesmo estado

⸻

2.2. Correção obrigatória:

Cada margem deve ter seu próprio estado de reação.

⸻

Estrutura correta:

const [reactions, setReactions] = useState({
  // marginId: emoji
});


⸻

Ao reagir:

const handleReact = (e, marginId, emoji) => {
  e.preventDefault();
  e.stopPropagation();

  setReactions(prev => ({
    ...prev,
    [marginId]: prev[marginId] === emoji ? null : emoji
  }));
};


⸻

Renderização:

Cada margem deve verificar apenas sua própria reação:

const selectedEmoji = reactions[margin.id];


⸻

2.3. Backend (se estiver usando)

A tabela já deve garantir:
	•	1 reação por usuário por margem

UNIQUE(margin_id, user_id)

Se trocar emoji:
→ fazer UPDATE
Se clicar no mesmo:
→ DELETE

⸻

2.4. Resultado esperado:
	•	reagir em um eco NÃO afeta outros ecos
	•	cada card funciona isoladamente
	•	estado correto por margem

⸻
