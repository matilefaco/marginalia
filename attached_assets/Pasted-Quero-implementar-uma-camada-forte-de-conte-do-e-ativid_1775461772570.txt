Quero implementar uma camada forte de conteúdo e atividade no app para que a comunidade pareça viva, interessante e movimentada desde já.

OBJETIVO GERAL:
Quero que o app tenha muito mais livros, muito mais ecos, mais comentários, mais reações e sensação constante de atividade social.

A ideia é fazer o Marginalia parecer uma comunidade real de leitores, mesmo enquanto a base de usuários ainda está crescendo.

==================================================
1. AUMENTAR MUITO A QUANTIDADE DE LIVROS NO APP
==================================================

Quero integrar o app com uma API pública de livros, de preferência Google Books API, para trazer muitos livros automaticamente.

O sistema deve permitir:
- buscar livros por gênero
- buscar livros por título
- buscar livros por autor
- paginar resultados
- salvar/cachear livros no banco para reutilização futura

IMPLEMENTAÇÃO:
Criar uma lógica backend para consumir Google Books API e expor rotas internas do app.

Rotas sugeridas:
- /api/books?genre=poesia&page=1&limit=8
- /api/books?search=clarice+lispector&page=1&limit=8
- /api/books/trending?page=1&limit=8

Cada livro retornado deve ter, quando possível:
- external_api_id
- title
- author
- description
- cover_url
- publisher
- publication_year
- total_pages
- language
- categorias/gêneros

IMPORTANTE:
- se o livro buscado ainda não existir na tabela books, salvar automaticamente ou fazer cache
- evitar chamadas repetidas desnecessárias à API
- manter paginação real
- exibir 8 livros por página nas listagens do app

==================================================

==================================================
3. CRIAR MUITA ATIVIDADE SOCIAL NO APP
==================================================

Quero implementar um sistema de seed/conteúdo inicial para que o app pareça movimentado.

Quero popular o app automaticamente com:
- usuários fictícios realistas
- ecos
- comentários
- replies
- reações
- ecos salvos
- livros com atividade
- métricas sociais iniciais

IMPORTANTE:
isso deve ser feito de forma elegante e plausível, sem parecer artificial ou exagerado.

==================================================
4. CRIAR USUÁRIOS SEED
==================================================

Quero um script ou lógica para criar usuários fictícios de comunidade, com perfis minimamente ricos.

Cada usuário seed deve ter:
- nome
- username único
- avatar ou iniciais
- avatar_color
- bio curta
- cidade opcional
- reader_type_title
- reader_type_description
- reading_signature
- preferências e gêneros de interesse, quando fizer sentido

Exemplos de perfis:
- leitora de Clarice e poesia
- leitor de clássicos e filosofia
- pessoa que lê fantasia e ficção científica
- pessoa que ama ensaio, psicanálise, feminismo etc.

Objetivo:
dar a sensação de diversidade real de leitores.

==================================================
5. CRIAR ECOS AUTOMÁTICOS
==================================================

Quero popular o app com muitos ecos distribuídos entre vários livros.

Esses ecos devem ser variados, com tipos como:
- insight
- citacao
- critica
- pergunta
- interpretacao

Cada eco deve conter:
- user_id
- book_id
- type
- quoted_excerpt (quando fizer sentido)
- content
- page_number ou chapter_label, quando fizer sentido
- created_at distribuído no tempo
- contagem plausível de reações e comentários

Quero que os ecos pareçam reais, com textos variados e naturais, por exemplo:
- reflexões emocionais
- leituras simbólicas
- perguntas abertas
- comentários sobre estilo do autor
- trechos marcantes
- observações sobre personagens

IMPORTANTE:
não repetir sempre o mesmo padrão de texto.

==================================================
6. CRIAR COMENTÁRIOS E REPLIES
==================================================

Quero que muitos ecos já tenham comentários e respostas.

Esses comentários devem:
- parecer naturais
- ter vozes diferentes
- variar entre concordância, discordância, aprofundamento e emoção

Exemplos de tons:
- “Eu senti isso também.”
- “Nunca tinha pensado dessa forma.”
- “Esse trecho me destruiu.”
- “Acho que aqui ela está falando mais sobre silêncio do que solidão.”
- “Pra mim esse ponto conversa com o final inteiro.”

Também quero replies em alguns comentários, para dar sensação de conversa viva.

==================================================
13. SISTEMA DE SEED
==================================================

Quero um script ou rotina clara de seed, algo fácil de rodar e rerodar.

Exemplo:
- npm run seed
ou equivalente

Esse seed deve criar:
- gêneros, se necessário
- livros iniciais
- perfis seed
- ecos
- comentários
- reações
- saved_ecos
- estatísticas coerentes

Também quero que esse seed:
- não crie usernames duplicados
- respeite foreign keys
- seja estável
- possa ser expandido depois

==================================================
14. MANTER USUÁRIO REAL SEPARADO DO SEED
==================================================

Muito importante:
não quero misturar dados seed com o usuário autenticado de forma errada.

O usuário real deve continuar tendo:
- seu próprio perfil
- seus próprios livros
- seus próprios ecos
- suas próprias reações
- suas próprias estatísticas

Os dados seed são para comunidade e contexto, não para falsificar a conta do usuário real.

==================================================
15. ESTATÍSTICAS E CONTAGENS COERENTES
==================================================

Quero que as métricas derivadas dos dados seed façam sentido.

Exemplo:
- um eco com 8 reações pode ter 2 comentários
- um livro com muitos ecos pode aparecer como mais debatido
- livros em alta devem refletir alguma atividade
- gêneros em alta devem refletir livros e ecos daquele gênero

Ou seja:
quero coerência mínima entre conteúdo e estatísticas.
