TEXTO PRONTO PARA COLAR NO REPLIT

Quero corrigir de forma completa os problemas de legibilidade e consistência visual do app, especialmente no dark mode, mantendo a identidade sofisticada do Marginalia, mas priorizando clareza real de leitura.

OBJETIVO GERAL

1) CORRIGIR A PALETA DO DARK MODE PARA FICAR MUITO MAIS LEGÍVEL

O dark mode atual está escuro demais com texto claro de menos, e vários elementos secundários estão quase invisíveis.

Ajustar os tokens de cor do dark mode

Quero substituir a lógica atual por uma hierarquia de contraste mais clara.

Novo esquema base para dark mode:
	•	background principal do app: #12100F
	•	background secundário / blocos internos: #181513
	•	card principal: #1E1A18
	•	card protegido / bloco oculto: #2A241F
	•	borda sutil: rgba(215, 198, 182, 0.16)
	•	borda mais visível em áreas importantes: rgba(215, 198, 182, 0.24)

Texto no dark mode:
	•	texto principal: #F3EDE5
	•	texto secundário: #D2C3B5
	•	texto terciário / metadata: #AE9E90
	•	texto muito sutil, mas ainda legível: #8E7F73

Cor de destaque:
	•	rose principal / accent: #D8B7A7
	•	rose hover / pressed: #E4C6B7

Elementos protegidos / spoiler / preview escuro:
	•	usar fundo mais separado do card, nunca quase da mesma cor
	•	fundo de bloco protegido: #332B24
	•	texto dentro do protegido: #E2D4C6
	•	texto secundário dentro do protegido: #BCA999

Regra importante

Nenhum texto pode usar opacidade tão baixa a ponto de ficar ilegível.
Evitar textos com opacity muito pequena como 0.35 / 0.4 em conteúdos relevantes.
Texto informativo precisa ficar no mínimo com contraste equivalente visual de texto secundário real.

2) CORRIGIR A ÁREA DE PREVIEW NA PUBLICAÇÃO

Na tela de publicação, a área de Preview · como vai aparecer no feed está quase invisível.
Isso precisa ser redesenhado para ficar totalmente compreensível.

	•	status de spoiler

Ajustes visuais do preview

	•	trecho em itálico com cor #EADFD4
	•	comentário principal com cor #F3EDE5
	•	metadados com cor #B7A697

Regra

O preview deve parecer um card real do feed, não um bloco apagado.

Melhorar estrutura interna do preview
	•	aumentar padding interno
	•	aumentar contraste entre o quote e o comentário
	•	separar quote e comentário com mais respiro
	•	deixar o preview com no mínimo 2 níveis claros de texto:

4) “VER MESMO ASSIM” PRECISA ABRIR O POST EM DARK MODE QUANDO O APP ESTIVER EM DARK MODE

Hoje, no dark mode, quando o usuário toca em “ver mesmo assim” em um post protegido, o post abre em aparência de modo padrão.
Isso está errado.

Corrigir lógica do tema

Quero que o estado de tema do app seja persistido e respeitado em toda navegação.

Regra obrigatória:

Se o usuário estiver em dark mode, qualquer post aberto a partir de:
	•	feed
	•	explorar
	•	perfil
	•	biblioteca
	•	post protegido
	•	“ver mesmo assim”

deve abrir mantendo dark mode, sem exceção.

O que verificar tecnicamente
	•	remover qualquer fallback que esteja resetando o tema ao abrir detalhe do post
	•	garantir que o tema venha de uma fonte global única
	•	usar o mesmo estado de tema em:
	•	páginas
	•	modais
	•	cards expandidos
	•	preview
	•	detalhe do post
	•	se existir contexto global de theme, garantir que a tela de detalhe consuma esse contexto corretamente
	•	se o tema estiver salvo em localStorage / banco / estado global, a abertura do post deve respeitar isso imediatamente

Resultado esperado

“Ver mesmo assim” deve apenas liberar o conteúdo protegido, sem trocar o tema visual da experiência.

5) MOSTRAR SEMPRE O NÚMERO DE COMENTÁRIOS NOS POSTS DE “MEUS POSTS” NO PERFIL

Na área Meus posts do perfil do usuário, às vezes existem comentários de outros usuários, mas isso não aparece no card.

Isso precisa ser corrigido.

Regra obrigatória

Todo post deve sempre exibir de forma explícita:
	•	número de reações
	•	número de comentários/respostas

mesmo dentro da área “Meus posts”.

O que fazer

Adicionar no card dos posts do perfil uma linha de metadados visível com algo como:
	•	12 reações
	•	3 comentários

ou, se preferir a linguagem do app:
	•	12 reações
	•	3 respostas

Mas essa informação precisa sempre aparecer, inclusive quando houver zero.

Exemplos:
	•	0 reações · 0 comentários
	•	8 reações · 2 comentários

Importante

Essa contagem deve refletir os dados reais do post e não pode sumir dependendo do tipo de post.
Precisa funcionar para:
	•	citação
	•	teoria
	•	leitura simbólica
	•	crítica
	•	qualquer outro tipo de margem
