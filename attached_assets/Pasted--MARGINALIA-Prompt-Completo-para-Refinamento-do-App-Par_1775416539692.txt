# MARGINALIA — Prompt Completo para Refinamento do App
## Para usar no Lovable / Claude Code

---

## CONTEXTO DO PRODUTO

**Marginalia** é uma plataforma de leitura social onde o texto deixa de ser estático e passa a ser um espaço vivo de pensamento coletivo. O nome vem das anotações feitas nas margens de livros ao longo da história.

**Tagline:** Leia junto. Sinta junto.

**Posicionamento:** Não é Kindle (consumo passivo), não é Goodreads (registro superficial), não é Twitter (fragmentação). É uma **Social Reading Platform** — leitura com profundidade social.

**Sensação desejada:** Um livro vivo. Uma experiência íntima. Uma comunidade silenciosa. Um espaço de descoberta emocional.

## IDENTIDADE VISUAL — SEGUIR RIGOROSAMENTE

### Símbolo da Marca
O ícone é a **orelha do livro (dog-ear)** — a dobra da página que leitores fazem quando não têm marcador. Três elementos:
1. **A página** — corpo preenchido em Doeskin (#BDAB9C), creme terroso, quente
2. **A orelha** — triângulo no canto superior direito em branco cremoso (#FAF8F3 com opacidade 0.55), a dobra em si
3. **O ponto na margem** — círculo pequeno em Old Vine (#697962) na margem esquerda da página, representando o leitor que já estava lá antes da anotação

### Paleta de Cores — EXATA
```css
--albescent:   #FAF8F3  /* fundo universal — 80-90% da interface */
--albescent-2: #EBE6DB  /* superfícies secundárias, cards */
--heather:     #AE8F7D  /* Heather Rose — destaques, anotações, ativo */
--doeskin:     #BDAB9C  /* Old Doeskin — símbolo, decorativo */
--old-vine:    #697962  /* Old Vine — confirmações, presença */
--metal:       #454545  /* Machine Gun Metal — texto principal */
--body-text:   #3D3D3D  /* texto de leitura */
```

Regras:
- 80-90% Albescent + Metal (silêncio)
- 10-15% Heather Rose (intervenção, emoção)
- 5% Old Vine (confirmação, presença)
- NUNCA preto puro #000 — sempre Metal #454545
- NUNCA branco puro #fff — sempre Albescent #FAF8F3

### Tipografia
```
Display/Leitura: Cormorant Garamond (Google Fonts)
  - Títulos: font-style italic, font-weight 300-400
  - Corpo de leitura: weight 400, size 17-18px, line-height 1.85
  - Citações: italic weight 400

Interface/UI: Jost (Google Fonts)
  - Labels: weight 300-400, letter-spacing 0.14-0.22em, uppercase
  - Botões: weight 400, letter-spacing 0.06em
  - Metadados: weight 300, size 11-12px
```

### Estética Geral
- Muito espaço negativo
- Bordas: 0.5px solid rgba(174,143,125,0.15-0.25)
- Border radius: 10-14px cards, 7-8px botões
- Textura de papel: `background-image: radial-gradient(circle, rgba(189,171,156,0.1) 1px, transparent 1px); background-size: 5px 5px`
- Sombras suaves: `box-shadow: 0 2px 16px rgba(69,69,69,0.05)`

## REGRA PRINCIPAL DE UX

O usuário deve entender em até 3 segundos:
1. "Estou lendo um livro"
2. "Posso marcar momentos"
3. "Posso ver o que outras pessoas sentiram nesses momentos"

**Tudo que não serve a isso deve ser simplificado ou removido.**

## HEATMAP — FEATURE CENTRAL

```css
/* Por capítulo: */
.heatmap-bar {
  height: 4-6px;
  background: #AE8F7D;
  opacity: /* varia 0.3 a 1.0 por intensidade */;
  border-radius: 3px;
  transition: all 0.3s ease;
}
/* Capítulos não lidos: */
.heatmap-bar.locked {
  background: #454545;
  opacity: 0.15;
  filter: blur(1px);
}
```

Anti-spoiler: capítulos além do progresso mostram "🔒 Você ainda não chegou aqui" em Jost 10px Metal 0.35.

## REMOVER / SIMPLIFICAR

- ❌ Múltiplos caminhos para a mesma ação
- ❌ Botões redundantes
- ❌ Mais de 2 CTAs primários por tela
- ❌ Qualquer cor fora da paleta definida
- ❌ Fundos escuros como cor de tela (Metal só para texto)
- ❌ Aparência de "rede social comum"

## ADICIONAR / REFORÇAR

- ✅ Dog-ear SVG decorativo nos cantos de cards (opacity 0.06-0.1)
- ✅ Textura de papel em fundos Albescent
- ✅ Rótulos de tipo em todo conteúdo (INSIGHT / REAÇÃO / TEORIA / DESTAQUE)
- ✅ Posição narrativa em todo conteúdo (Capítulo X · XX%)
- ✅ Anti-spoiler obrigatório (bloqueio visual além do progresso)
- ✅ Ponto Old Vine na margem após publicar anotação
- ✅ Cards compartilháveis — mínimo 3 tipos por livro
- ✅ Loop visual: Ler → Marcar → Ver ecos → Gerar card → Compartilhar → Voltar
