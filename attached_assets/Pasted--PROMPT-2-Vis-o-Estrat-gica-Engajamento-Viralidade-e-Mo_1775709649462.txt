## BLOCO A — STREAKS DE LEITURA (engajamento diário)

### O que é

Um contador de dias consecutivos que o usuário postou ou reagiu a algo. Aparece discretamente no perfil e no header.

### Implementação

**Lógica de streak** — criar `src/utils/streak.ts`:

```typescript
const STREAK_KEY = (uid: string) => `mg_streak_${uid}`;
const LAST_ACTIVITY_KEY = (uid: string) => `mg_last_activity_${uid}`;

export function getStreak(uid: string): number {
  return parseInt(localStorage.getItem(STREAK_KEY(uid)) ?? "0");
}

export function updateStreak(uid: string): number {
  const today = new Date().toDateString();
  const lastActivity = localStorage.getItem(LAST_ACTIVITY_KEY(uid));

  if (lastActivity === today) {
    // Já registrou hoje — não muda streak
    return getStreak(uid);
  }

  const yesterday = new Date(Date.now() - 86400000).toDateString();
  const currentStreak = getStreak(uid);

  if (lastActivity === yesterday) {
    // Dia consecutivo — incrementa
    const newStreak = currentStreak + 1;
    localStorage.setItem(STREAK_KEY(uid), String(newStreak));
    localStorage.setItem(LAST_ACTIVITY_KEY(uid), today);
    return newStreak;
  } else {
    // Quebrou — reinicia do 1
    localStorage.setItem(STREAK_KEY(uid), "1");
    localStorage.setItem(LAST_ACTIVITY_KEY(uid), today);
    return 1;
  }
}
```

Chamar `updateStreak(uid)` sempre que o usuário:

- Publicar um post
- Reagir a um post
- Adicionar um livro à biblioteca

**Exibição no perfil:**

- Se streak >= 3: mostrar `🔥 N dias` em Jost 13px, cor `#AE8F7D`, ao lado do username
- Se streak >= 30: mostrar `🔥 N dias` em cor `#697962` (Old Vine) — destaque especial
- Se streak = 0 ou 1: não mostrar nada

**Exibição no header do Home:**

- Badge discreto `🔥 N` no canto do avatar do usuário (se existir avatar no header)

## BLOCO C — “LEITORES COMPATÍVEIS” no Explorar

### O que é

Uma seção na tela Explorar que mostra outros leitores com perfil similar ao do usuário atual. Cria senso de comunidade e incentiva seguir pessoas.

### Implementação

**Algoritmo de compatibilidade** (baseado em gêneros do onboarding):

```typescript
function getCompatibleReaders(currentUser: User, allUsers: User[]): User[] {
  const myGenres = new Set(currentUser.genres ?? []);

  return allUsers
    .filter(u => u.id !== currentUser.id)
    .map(u => {
      const theirGenres = new Set(u.genres ?? []);
      const intersection = [...myGenres].filter(g => theirGenres.has(g));
      return { user: u, score: intersection.length };
    })
    .filter(({ score }) => score > 0)
    .sort((a, b) => b.score - a.score)
    .slice(0, 5)
    .map(({ user }) => user);
}
```

**Card de leitor compatível:**

```
[Avatar]  @username                    X gêneros em comum
          O Analista · 34 posts        [ Ver perfil ]
```

- Avatar colorido (já existe no app)
- Username em Jost 14px `#1E1C19`
- Arquétipo + contagem de posts em Jost 12px `#7A726A`
- “X gêneros em comum” em Jost 12px `#697962`
- Botão “Ver perfil” que navega para `/profile/:userId`

**Posição no Explorar:** após a seção de coleções editoriais, antes de “Em debate”.
