IMPLEMENTAÇÃO — NOVO PERFIL + SISTEMA DE CARDS COMPARTILHÁVEIS

==================================================
PARTE 1 — ESTRUTURA DO PERFIL
==================================================

Reorganizar o perfil do usuário na seguinte ordem:

1. HEADER DE IDENTIDADE
2. ASSINATURA
3. DNA DE LEITURA
4. IMPRESSÃO DE LEITURA
5. CARD COMPARTILHÁVEL

--------------------------------------------------
1.1 HEADER
--------------------------------------------------

Exibir:

- Nome do usuário
- Username (ex: @matilefaco) → clicável
- Cor de identidade (bolinha)
- Tipo de leitor

Adicionar botão:
“Compartilhar identidade”

--------------------------------------------------
1.2 ASSINATURA
--------------------------------------------------

Texto curto e emocional do leitor

Ex:
“Cada livro me deixa diferente”

--------------------------------------------------
1.3 DNA DE LEITURA
--------------------------------------------------

Exibir como métricas visuais:

- Sensível
- Analítico
- Intenso
- Curioso

Formato:

Sensível — 78%
Analítico — 62%
Intenso — 85%
Curioso — 70%

--------------------------------------------------
1.4 IMPRESSÃO DE LEITURA
--------------------------------------------------

Bloco mais emocional:

Exemplo:

“O Observador  
Leitor sensível  
Ama frases que doem devagar”

--------------------------------------------------
1.5 CARD PRINCIPAL
--------------------------------------------------

Criar um card único para compartilhamento.

Formato:

Nome
Perfil de leitor • ano

Traços principais:
- Sensível
- Analítico
- Intenso

Assinatura abaixo

Botão:
- Baixar
- Compartilhar

==================================================
PARTE 2 — SISTEMA DE CARDS (VARIAÇÕES)
==================================================

Criar sistema modular de cards.

Cada tipo é uma variação do mesmo layout base.

--------------------------------------------------
2.1 CARD IDENTIDADE (PRINCIPAL)
--------------------------------------------------

Conteúdo:

- Nome
- Username
- Tipo de leitor
- Métricas
- Assinatura

Uso:
- perfil
- compartilhamento

--------------------------------------------------
2.2 CARD FRASE + LEITOR
--------------------------------------------------

Conteúdo:

- Trecho (grande)
- Comentário do usuário
- Nome + username (clicável)
- Livro + autor

Uso:
- compartilhamento de post

--------------------------------------------------
2.3 CARD PERFIL EMOCIONAL
--------------------------------------------------

Conteúdo:

“Você sente livros assim:”

- 💔 se toca fácil
- 🔥 sente intensamente
- 🧠 analisa profundamente

--------------------------------------------------
2.4 CARD MOMENTO DE LEITURA
--------------------------------------------------

Conteúdo:

- Livro atual
- Progresso (ex: 26%)
- Trecho atual
- Reação emocional

--------------------------------------------------
2.5 CARD MINIMAL
--------------------------------------------------

Conteúdo:

- Apenas frase
- Pequena assinatura

Sem UI pesada

--------------------------------------------------
2.6 CARD DNA VISUAL
--------------------------------------------------

Conteúdo:

- Barras de leitura
- Nome do usuário
- Identidade visual forte

==================================================
PARTE 3 — COMPORTAMENTO
==================================================

- Cada card deve ser exportável como imagem
- Formatos:
  - Stories (9:16)
  - Feed (1:1)

- O usuário NÃO escolhe entre muitos tipos ao mesmo tempo
- Cada ação gera um card específico automaticamente

Exemplo:

Clicar em compartilhar perfil → gera card identidade
Clicar em compartilhar trecho → gera card frase

==================================================
PARTE 4 — OBJETIVO
==================================================

- Reduzir confusão
- Aumentar clareza
- Criar compartilhamento natural
- Tornar o perfil desejável
- Aumentar viralidade orgânica
